# merk-audio

Recorded German sentences for [merk](https://github.com/tomrenard/merk), served by GitHub Pages at
`https://tomrenard.github.io/merk-audio/a/<key>.m4a`. Generated by `scripts/gen-audio.ts` in merk;
`<key>` is `audioKey(sentence)` from `src/lib/audio.ts`. Voices: Gemini TTS (Kore, Charon).
